# Clases

Documentos de texto con el contenido de cada clase, separados por nivel:

- `nivel-1/` → 16 clases del curso introductorio.
- `nivel-2/` → 16 clases del curso avanzado, con foco en análisis de datos (archivos CSV, estadística
 básica y gráficos con matplotlib).

Cada archivo `.txt` contiene el código y los comentarios tal como se trabajan en clase, en el orden
en que se van escribiendo — no son notebooks de Jupyter, sino transcripciones simples pensadas para
leer, imprimir o tipear directamente.
